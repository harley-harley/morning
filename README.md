Goal of this project is to design an alarm clock based on ambient brightness.

The speaker will play a tune once a photosensor has dectected that light has reached a certain brightness.
Once the tune has finished playing, the alarm will not play again until reset.
The reset will be triggered once the photosensor has gone dark for some amount of time.

I will be keeping things as simple, this is mostly for me to get practice coding drivers and writing programs for embedded systems.
